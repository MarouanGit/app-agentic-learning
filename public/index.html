🤖 Agentic Learning

Un assistant d'apprentissage qui connaît le contenu du LMS DATAROCKSTARS, en français, avec citations vérifiées et refus motivés.

Vision

Agentic Learning transforme l'apprentissage en ligne en étant un tuteur toujours disponible qui :

  • Connaît tout le contenu du LMS (cours, labs, quizz, exemples)
  • Répond en français avec citations exactes cliquables
  • Refuse clairement quand c'est hors programme (6 portes de refus motivés)
  • Adapte son aide au mode demandé (aide, indice, explication)
  • Autocomplète le code discrètement dans les éditeurs

Contrat API

POST /api/ask

Poser une question sur le contenu du LMS.

{
  "question": "Pourquoi GROUP BY avant WHERE ?",
  "mode": "aide",
  "autorises": ["sql-bases"]
}

Réponse :

{
  "statut": "reponse",
  "texte": "En SQL, on utilise WHERE **avant** GROUP BY...",
  "citations": [{
    "cours": "sql-bases",

    "url": "https://app-lms.vercel.app/..."
  }]
}

Les 6 portes de refus

Agentic Learning ne hallucine pas. À chaque question, 6 filtres vérifient si on peut répondre :

1️⃣ Requête valide ?

Question vide ou trop générique → refus.

2️⃣ Question assez précise ?

Trop vague, pas de verbe d'action → refus.

3️⃣ Pertinence ?

Aucune leçon pertinente → « Hors programme ».

4️⃣ Contenu exploitable ?

Pertinent, mais aucune citation utilisable → refus.

5️⃣ Accès autorisé ?

Contenu payant/retiré → filtrage selon droits.

6️⃣ Vérification post-réponse ?

Réponse a vraiment utilisé le contenu ?

Infos techniques

  • Modèles : Qwen2.5 0.5B, e5-small (ONNX, CPU)
  • Latence cible : <300 ms pour /api/ask
  • Infrastructure : Vercel Functions (Node.js 24)
  • Authentification : Bearer token (AGENTIC_SECRET)
  • Index : BM25 + embeddings denses + ontologie
  • Coûts : ~$1–3/mois (CPU uniquement)
